# 💊 Smart Medicine Reminder

An AI-powered medicine reminder application built with **React, TypeScript, and Vite**. The application helps users manage their medicines, receive reminder notifications, track missed doses, and understand medications through AI-powered explanations.

# 📖 About the Project

Smart Medicine Reminder is a modern web application designed to help users remember their daily medicines. The system allows users to schedule medicines, receive reminders, monitor medication history, and get AI-generated medicine explanations in simple language.

---

# ✨ Features

- 💊 Add medicines
- ⏰ Schedule medicine reminders
- 🔔 Reminder notifications
- ✅ Mark medicines as Taken
- ❌ Track missed doses
- 📅 Daily medication schedule
- 📊 Medication history
- 🤖 AI-powered medicine explanations
- 📱 Responsive user interface
- ⚡ Fast performance using Vite

---

# 🤖 AI Features

The AI assistant can:

- Explain medicines in simple language
- Describe medicine usage
- Provide basic dosage guidance
- Show possible schedule conflicts
- Offer general medication safety information

> **Disclaimer:** AI responses are for educational purposes only and should not replace advice from a healthcare professional.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/tajmoin595-blip/Smart-Medicine-Reminder1.git
```

Go to the project folder

```bash
cd Smart-Medicine-Reminder1
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
